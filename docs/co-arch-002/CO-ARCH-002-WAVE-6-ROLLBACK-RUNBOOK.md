# CO-ARCH-002 — Wave 6 Rollback Runbook

**Program:** CO-ARCH-002  
**Wave:** 6 — Cutover & Stabilization  
**Status:** Ready for use after Wave 6 ARB approval (when flags are enabled in pilot)  
**Delivery rule:** Wave 6 ships with **all flags OFF** — this runbook is for post-authorization emergencies.

---

## Principle

Rollback restores Soft Go-Live behaviour by disabling Deal cutover flags.  
Enterprise Deal rows are **retained** (minimum 30 days). Do not hard-delete.

Automation helpers:

- `buildDealEmergencyRollbackSteps()` / `buildDealIdleFlagEnvLines()` — `src/lib/enterprise-deal/rollback-automation.ts`
- Architecture Health → **Copy idle flag matrix** / **Clear reconcile log**
- Artifact: `docs/co-arch-002/CO-ARCH-002-WAVE-6-IDLE-FLAG-MATRIX.env.txt`

---

## Emergency sequence (fastest UX restore)

1. **Immediate** — `DEAL_REGISTRY_BLOCK_LOCAL_WRITE=false`
2. **Immediate** — all `DEAL_REGISTRY_CONSUMER_*` + `NEXT_PUBLIC_*` mirrors = `false`
3. **Immediate** — `DEAL_REGISTRY_PORT_RUNTIME` + public mirror = `false`
4. **Follow-up** — `DEAL_REGISTRY_DUAL_WRITE` + public mirror = `false`
5. **Follow-up** — `DEAL_REGISTRY_SHADOW_READ` + public mirror = `false`
6. **Follow-up** — optionally `DEAL_REGISTRY_API_ENABLED` + public mirror = `false` (API 404)

Then: redeploy / restart so client `NEXT_PUBLIC_*` mirrors reload.

## Post-rollback checks

| Check | Expected |
|-------|----------|
| My Deals | Local LoanFile rows (Soft Go-Live) |
| Loan / Opportunity Workspace | DAL → legacy (consumer flags OFF) |
| Dual-write traffic | Stopped |
| Deal rows in Postgres | Still present (retain) |
| Architecture Health | Idle (flags OFF) |

---

## What rollback does NOT do

- Does not delete Enterprise Deals
- Does not wipe browser LoanFiles
- Does not require schema rollback
- Client “Clear reconcile log” only clears local diagnostics
