**Status:** Framework delivered · **Reports only** · No runtime behaviour change

**Governing ADR:** [ADR-022](../adr/ADR-022-enterprise-ai-orchestrator-conversational-reasoning.md)

- No live SARATHI dialogue changes  
- No Hybrid Cutover  
- No UI  
- No deploy

---

## 1. Purpose

Create an evaluation framework that scores consultation conversations against **Rupee Catalyst consultant behaviour** across eight dimensions — so every scored conversation receives a benchmark score and report.

This is the mandatory quality gate input before Hybrid Cutover (Phase 3).

---

## 2. Benchmark dimensions (frozen)

| # | ID | Label |
|---|----|-------|
| 1 | `intent_understanding` | Intent Understanding |
| 2 | `technical_accuracy` | Technical Accuracy |
| 3 | `consultation_quality` | Consultation Quality |
| 4 | `natural_conversation` | Natural Conversation |
| 5 | `customer_trust` | Customer Trust |
| 6 | `completeness` | Completeness |
| 7 | `best_next_question` | Best Next Question |
| 8 | `business_safety` | Business Safety |

Each dimension is scored **0–100**.  
**Overall** = mean of eight dimensions.  
**Grade:** A ≥85 · B ≥75 · C ≥65 · D ≥50 · F &lt;50.

## 4. Architecture (offline)

```text
Conversation turns (fixture | captured live | shadow)
        │
        ▼
  Rubric evaluators (8 dimensions)
        │
        ▼
  Conversation score + grade
        │
        ▼
  Suite report (by product · by dimension)
        │
        ▼
  Markdown / JSON report artefacts
```

**Not connected** to `turn-orchestrator` facing text.

## 7. Rubric notes (W2 foundation)

W2 uses **deterministic heuristic rubrics** (banned generics, invented EMI/rate/approval patterns, answer-first shape, advance questions, product cue reflection).  

Later waves may add LLM-as-judge or human rater overlays **without** changing these dimension IDs.

**Business Safety** enforces ADR-022: model must not invent engine outputs or imply CRM/workflow execution.
