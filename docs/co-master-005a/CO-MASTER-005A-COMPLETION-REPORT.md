# CO-MASTER-005A — Lender Program Portal Multi-Product Invitations

## Core model

One invitation → **one lender** + **one or more** Product Master products via explicit join rows:

```text
LenderProgramPortalInvite
        ↓
LenderProgramPortalInviteProduct
        ↓
EnterpriseProduct
```

No JSONB `product_ids`, no comma-separated products, no hardcoded portal product list.

---

## Database

- Additive migration: `prisma/migrations/20260810220000_co_master_005a_invite_products/migration.sql`
- Table: `lender_program_portal_invite_products`
- Unique `(invite_id, product_id)`
- FKs to organizations, invites (cascade), enterprise_products (restrict)
- No reset / truncate / destructive deletes

---

## New invitations

1. Select lender  
2. Multi-select products from **current** Product–Lender Matrix only  
3. Minimum 1 product  
4. Persist invite + invite-product rows (code/label snapshot for display/audit)

## Authorization (server)

`Invitation → Lender → Explicit invitation products`

- `resolveToken` returns **only** invite-product rows  
- `submitProgram` rejects out-of-scope product with **403** `PRODUCT_NOT_IN_INVITE_SCOPE`  
- Missing scope → **403** `INVITE_PRODUCT_SCOPE_MISSING`

## Legacy BC-3

Script: `npm run backfill:co-master-005a-bc3`

1. Find invites with zero product rows  
2. Snapshot current Matrix → Product Master matches  
3. Create invite-product rows  
4. Preserve original invite  
5. If no mapped product → **STOP that invite** and report (no invent)

Future Matrix changes do **not** expand old invite scope.

Report artefact: `docs/co-master-005a/CO-MASTER-005A-BC3-BACKFILL-REPORT.md` (generated by backfill)
