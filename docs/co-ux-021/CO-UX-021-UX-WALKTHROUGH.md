# CO-UX-021 — UX Walkthrough

**Audience:** Product Owner / BAT  
**Deploy:** Not deployed until PO approval

## 1. Capture a note (any business workspace)

1. Open Opportunity Workspace, Lender Lifecycle (Deal), Customer 360, or Accounting.
2. Locate the compact **Notes** (sticky-note) icon in the header / command bar — icon-only, `h-8 w-8`.
3. Click → **Business Note** dialog opens.
4. Type observation / meeting summary / follow-up.
5. Optionally select a **Category**.
6. **Save** → toast confirms; **Cancel** closes without write.

## 2. Notes panel

1. Open the workspace **Notes** tab (or Accounting **Notes** workbench).
2. Notes list: **pinned first**, then newest first.
3. Use **Search** (e.g. `GST`) to filter by body text.
4. **Pin** one note per entity — previous pin clears automatically.
5. **Soft delete** removes from list; row retained with audit fields (no hard delete).

## 3. What the user should *not* see

- Redesigned Opportunity Workspace layout  
- Redesigned Lender Lifecycle chrome  
- Personal notepad branding  
- Permanent delete control  

## 4. Five Second Rule

Header Notes icon answers: “Where do I capture an official business observation?”  
Notes tab answers: “What has been recorded on this entity?”
