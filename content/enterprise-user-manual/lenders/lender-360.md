# Lenders and Lender 360°

## Enterprise Lender Directory

Open **Enterprise Lender Directory** from primary navigation to search and select lenders from the Enterprise Lender Registry.

Strategy Manual Recommendation and Deal-eligible lender selection must use the **Prisma Enterprise Lender Registry** — not soft demo catalogs as production truth.

## Lender 360°

Lender 360° summarises relationship intelligence for a lender, including:

- Lender identity and registry facts
- Related deals / opportunities projections where available
- Activity timeline scoped to the lender
- Insights surfaces that consume enterprise data (advisory only)

## How to open Lender 360°

1. Open Enterprise Lender Directory.
2. Search and select a lender.
3. Review the summary / 360° intelligence panel and related tabs.

## Lender Program Portal (admin)

Administrators can manage lender self-service programme update tokens and submissions under Administration (Lender Program Portal). Live Product / Lender programme SSOTs update only after Administrator **Publish** — portal submissions are staging + approval, not a parallel SSOT.

## Warnings

> Never swallow lender API failures as an empty list on Deal-eligible paths. Show the error so operators can retry.
