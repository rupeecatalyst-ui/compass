# Administration Console

Administration opens a single hub — the **Administration Console** — instead of expanding dozens of modules in the left rail.

## How to navigate

1. Open **Administration** from primary navigation.
2. Use category cards (Organization, Identity & Access, Workflow, Products, Masters, Lenders & Partners, AI, Enterprise Configuration, System, and **User Manual**).
3. Search configuration modules from the console search box.
4. Open a module card to enter that admin workspace.

## User Manual ownership

The **User Manual / Knowledge Center** is an **enterprise Administration** capability.

- Individual modules may contribute Markdown articles.
- Modules do **not** own the User Manual.
- Marketing documentation is a **section** inside this central manual — not a Marketing-owned manual app.

## Permissions

`/admin/*` routes require **Admin** or **Super Admin**. Do not expose confidential system configuration procedures to ordinary operators merely because documentation exists — keep sensitive ops under admin-only articles and System Administration modules.
