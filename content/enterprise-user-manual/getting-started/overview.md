# Catalyst One Getting Started

Catalyst One is the Rupee Catalyst **enterprise operating system** for loan acquisition, opportunity and deal execution, lender programmes, communication, and administration.

This User Manual is the central operational documentation system. It lives under **Administration → Administration Console → User Manual**.

## Who this manual is for

- **Administrators / Super Admins** — configure the platform and use Administration Console modules.
- **Operators** — day-to-day Contacts, Opportunities, Deals, Documents, and Loan Workspace (where their role permits).

The in-app User Manual route is under `/admin`, so only **Admin** and **Super Admin** roles can open it today. Module procedures still describe operator workflows so administrators can train teams.

## Primary navigation (left rail)

Typical Column 1 destinations:

1. **Dashboard** — RM / operational home
2. **CHANAKYA Radar** — operational intelligence
3. **Contacts** — Enterprise Contact Master
4. **My Opportunities** — Opportunity Registry
5. **My Deals** — Deal Registry
6. **Loan Journey** — Execution Hub orchestration
7. **Tasks** — Enterprise Task Engine projection
8. **Documents** — Opportunity Document Center entry
9. **Enterprise Lender Directory** — lenders and Lender 360°
10. **Accounting** — accounting workspaces (where enabled)
11. **Mission Control** / **Horizon** — supervisory surfaces
12. **Administration** — opens the Administration Console
13. **Settings** — user/settings surfaces

Do not treat Administration as a place to park day-to-day operational workspaces.

## Canonical business journey (high level)

```text
Contact
 → Start Loan Journey / Draft Opportunity
 → Lead Information (requirement capture)
 → Opportunity Workspace (Documents → Credit → Strategy)
 → Deal(s) per lender
 → Loan Workspace / Lender Pipeline
```

Exact stage names and CTAs follow the certified Business Journey Navigator inside each workspace.

## How to open the User Manual

1. Sign in as an **Admin** or **Super Admin**.
2. Open **Administration** from the left navigation.
3. On the Administration Console, open the **User Manual** category (or search “User Manual”).
4. Use **Search**, **Categories**, and the **table of contents** to find procedures.

## Warnings

> **Do not invent business values.** Uncaptured fields should remain Not Specified / Pending Input. Catalyst One follows CAD-2026-001 (Business Data Provenance).

> **Marketing live send is gated.** Marketing Command Center authoring may be available while live bulk execution remains off until Product Owner authorises production flags. See Marketing articles.
