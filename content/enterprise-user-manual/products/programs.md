# Products and Programs

Product and programme configuration lives in the **Administration Console** under Product & Program (and related masters). Operational desks consume these masters — they do not hardcode product catalogues.

## Typical admin entry points

From Administration Console:

- **Product Library** — product registry and lifecycle
- **Product–Lender Matrix** — which lenders participate for which products
- **Home Loan / LAP / Personal Loan / UBL Lender Priority** — priority configuration desks
- **Product Programs** — programme metadata where configured
- **Document Types** — document type masters used by Document Center / LOD

Exact module cards are searchable on the Administration Console home.

## How to update a product programme (operator view)

1. Confirm you have Admin access.
2. Open Administration → Administration Console.
3. Open **Product & Program** (or search the module name).
4. Edit only through the certified admin workspace for that master.
5. Publish / save according to that module’s controls.

## Lender Program Portal vs Product Master

Lender self-service submissions stage programme updates for approval. **Publish** into Enterprise Lender Program / Lender Registry is the only path that updates live programmes.

## Warnings

> Do not hardcode product pages or product availability in companion apps. Catalyst One owns entitlements and product definitions.
